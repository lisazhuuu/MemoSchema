# LLMs4SchemaDiscovery-style baseline

This directory contains the automatic, no-human-feedback baseline used with
MemoSchema:

- Stage 1: process specification to initial schema
- Stage 2: seed PDFs to refined schema
- Stage 3: target-run corpus to final schema

In the paper (Table IV) the baseline runs on each of the 27 evaluation corpus instances r7–r9
(COF/MOF/ZIF × seed sets 01–03), three repetitions each, via `scripts/run_memexp27.sh`, which takes one command
per run and repetition from `scripts/memexp27.py jobs <batch>`:

- Stage 2 input: the seed PDFs of that instance, `seeds/seed_chem/<SUB>_<SET>/` (all readable PDFs, sorted).
- Stage 3 input: the `cumulative_corpus/` PDFs of the same r7–r9 instance
  (`results/e2e/e2e_v3/<batch>/chem/<SUB>_<SET>/iterative_phase1_chem_*/cumulative_corpus`). When the corpus holds
  more than 40 PDFs, 40 are sampled from the sorted file list with `random.Random(42)`; the sample equals the
  original only if exactly the same files are present.
- Batch size 5, at most 8 final fields.

Run from the MemoSchema repository root; one command as generated by `memexp27.py jobs`:

```bash
python llm4schema/scripts/run_llms4schema_baseline.py \
  --domain chem \
  --subdomain COF \
  --last-tier "Covalent Organic Frameworks (COFs)" \
  --seed-dir seeds/seed_chem/COF_02 \
  --stage3-corpus-dir results/e2e/e2e_v3/r7/chem/COF_02/iterative_phase1_chem_<timestamp>/cumulative_corpus \
  --output-root results/memexp27/l4s_raw/e2e7/rep1/COF_02
```

`--max-stage3-papers 40`, `--batch-size 5` and `--max-final-fields 8` are the defaults.

Primary output:

```text
<output-root>/final_schema_from_cumulative_corpus/final_schema.json
```
